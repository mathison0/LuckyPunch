# v15 — 리시브 2단 반격 상태머신

> `src/code-here/LuckyPunch_v15.js` · v14 기반 · 직접 반격 실패 시 통제 셀프세팅

## 한 줄 요약

v14의 서브 공격과 EARLY/MULTI 수비 적응은 그대로 둔다. 리시브에서 직접
반격이 두 번 연속 막힌 상대에게만 첫 터치를 자기 코트에 세우고, 두 번째
접촉에서 기존 파워히트 탐색기로 공격한다.

## 상태머신

```text
RECEIVE
  ├─ 직접 반격 표본 < 2 또는 승률 >= 45% → 기존 직접 반격
  └─ 직접 반격 승률 < 45% → SET_PLANNED
                              ├─ 실제 첫 접촉 전: 셀프세팅 위치 유지
                              └─ 첫 접촉 감지 → SECOND_ATTACK
                                                   └─ 공이 네트를 넘음 → RECOVER
```

초기 구현은 계획을 고른 틱에 곧바로 `committed`로 표시했다. 다음 틱에는
일반 클리어 위치로 되돌아가 실제 행동이 v14와 같아지는 상태 전이 버그였다.
`SET_PLANNED`를 실제 첫 접촉까지 유지한 뒤에야 성능이 변했다.

## 공격성 보존 장치

- 자기 서브에는 이 상태머신을 적용하지 않는다.
- 리시브 첫 두 번은 v14의 직접 반격으로 상대를 시험한다.
- 셀프세팅을 한 번 시험한 뒤에는 직접 반격과 셀프세팅의 실제 랠리 승률 중
  높은 쪽을 사용한다.
- 예상 접촉 x가 70보다 작은 깊은 코너 공은 직접 클리어가 이미 안전하므로
  셀프세팅하지 않는다.
- 셀프세팅은 공 중심과 3~30px 떨어진 몸통 접촉을 시뮬레이션해 공이
  `x < 206`에 남는 후보만 허용한다.

상성이라, 이 두 결과를 승리로 해석하지 않는다.

`decide`는 전체 검사에서 평균 0.14~0.20ms, 최대 14.3ms로 120ms 예산 안이다.
