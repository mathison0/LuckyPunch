# v16 — 점수차 기반 리시브 복구 상태머신

> `src/code-here/LuckyPunch_v16.js` · v15 기반 · 최저 승률 우선 최종판

## 한 줄 요약

동점이나 리드에서는 가장 공격적인 직접 반격을 유지한다. 한 점이라도 뒤지면
리시브 첫 터치를 자기 코트에 세우고 두 번째 접촉으로 공격해 템포를 바꾼다.
점수를 만회해 동점이 되면 즉시 직접 반격으로 복귀한다.

## 왜 v15의 승률 학습을 바꿨나

v15는 직접 반격과 셀프세팅의 랠리 승률을 세트 안에서 학습했다. v09·v10에는
강했지만 비슷한 계열인 v13·v14와는 랠리 49.4%, 세트 41.7~45.8%였다.
짧은 10점 세트에서 몇 번의 승패로 상대를 분류하면 탐색이 끝나기 전에 경기가
기울거나, 우연한 1승 때문에 잘못된 템포를 잠그는 문제가 있었다.

고정 대조에서는 직접 반격이 v14·v02에 좋고 셀프세팅이 v13에 좋았다. 상대
이름이나 불안정한 행동 분류 대신 현재 점수차를 사용하면, 직접 반격으로 밀리는
경기에서만 다른 템포를 꺼내고 이기고 있는 경기의 공격성은 보존할 수 있다.

## 상태머신

```text
새 리시브 랠리
  ├─ scoreSelf >= scoreOpp → DIRECT_COUNTER
  └─ scoreSelf <  scoreOpp → SET_PLANNED
                               ↓ 실제 첫 접촉
                             SECOND_ATTACK
                               ↓ 공이 네트를 넘음
                             RECOVER

득점해 동점 복구 → 다음 리시브부터 DIRECT_COUNTER
```

점수차 게이트 대조:

| 셀프세팅 전환 | v13 | v14 | v02 | v15 |
|---|---:|---:|---:|---:|
| 1점 열세 | **54.2%** | **54.2%** | **54.2%** | **60.4%** |
| 2점 열세 | 41.7% | 50.0% | 66.7% | 54.2% |
| 3점 열세 | 45.8% | 50.0% | 66.7% | 54.2% |

2점까지 기다리면 v13전은 이미 복구하기 어려워 1점 게이트를 채택했다.

## 판단

모든 기존 LuckyPunch 제출 파일과 PikaPlanner 두 버전에 공식 프로토콜상
세트 승률 54.2% 이상을 기록한 첫 버전이다. 상대 구성이 넓거나 알 수 없는
실전 제출에는 v16을 사용한다. v09·v10만 집중 공략한다면 평균 공격력이 더
높은 v15가 여전히 특화 선택지다.
