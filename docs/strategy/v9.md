# v9 — 첫 서브 고속 아치

> `src/code-here/LuckyPunch_v9.js` · v7 기반

## 한 줄 요약

랠리의 첫 서브만 `|vx|=20, y=-1` 고속 아치로 고정한다. v7의 나머지 공격·수비는
그대로 유지하면서 v3·v4 계열의 점프 타이밍을 무너뜨리고, v5 이후의 강한 상대에게는
성능을 잃지 않는다.

## 출발점과 수정된 가설

v7 랠리 분해에서 v5·v6 상대 서브 랠리 승률은 약 14%, 리시브 랠리는 약 90%였다.
처음에는 느린 아치로 상대에게 선공을 넘기면 v7의 강한 리시브를 활용할 수 있다고
생각했다. 실측 결과 이 설명은 틀렸다.

- 느린 아치(`|vx|=10, y=-1`)는 기본 AI 상대 세트 승률을 58%에서 38%로 낮췄다.
- 고속 아치(`|vx|=20, y=-1`)는 강한 상대의 서브 랠리 열세를 뒤집지는 못했다.
- 대신 v3·v4처럼 가장 이른 접촉에 강하게 의존하는 구형 공격형 봇의 수신·점프
  타이밍을 크게 흔들었다.

따라서 채택 근거는 "선공권 양보"가 아니라 **첫 공의 수직 궤적 다양화가 구형 수비의
타이밍 가정을 깨면서도 최신 maximin 수비에는 손해가 없다는 것**이다.

## 구현

`meta.isPlayer2Serve`, 진영, 네트 통과 횟수를 함께 사용해 진짜 첫 서브만 식별한다.
첫 접촉에서는 v7의 `chooseHit()` 결과 대신 고속 아치를 사용하고, 공이 한 번이라도
네트를 건넌 뒤에는 v7 로직으로 완전히 복귀한다.

```js
var openingServe =
  OPENING_SERVE === 1 &&
  myServe &&
  rallyCrossings === 0 &&
  possessionTouches === 0;

var best = openingServe
  ? { score: 0, hit: 1, xMag: 1, yDir: -1 }
  : chooseHit(...);
```

정지 구간에서는 `rallyCrossings`를 0으로 초기화한다. 득점 후 얼어붙은 입력이 다음
랠리의 첫 점프를 오염시키는 기존 함정을 다시 만들지 않는다.

## 성적

lag1, 지터 `{0,8}`, 양 진영, 상대당 48세트의 랠리 계측:

| 상대 | v7 랠리 | v9 랠리 | v7 세트 | v9 세트 |
|---|---:|---:|---:|---:|
| v1 | 83.2% | **86.2%** | 100.0% | 100.0% |
| v2 | 61.3% | **68.4%** | 85.4% | **93.8%** |
| v3 | 73.8% | **93.4%** | 100.0% | 100.0% |
| v4 | 73.2% | **92.7%** | 100.0% | 100.0% |
| v5 | 51.1% | 50.8% | 54.2% | 54.2% |
| v6 | 51.4% | 51.6% | 56.3% | **58.3%** |
| v7 | — | 50.0% | — | 52.1% |

지터 8, 양 진영, 상대 AI·v1·v2·v3, 각 24세트의 lag 1/2/3 종합 벤치:

| | 종합 승률 | 득실 |
|---|---:|---:|
| v7 | 77.4% | 2658-1701 |
| v9 | **81.9%** | **2691-1464** |

lag1 기본 AI만 보면 v7 83%, v9 79%로 1승 차이 후퇴했다. 반면 v2는 83%→96%,
v3는 100%를 유지했고 전체 득실은 크게 개선됐다. 기본 AI 한 칸의 소폭 회귀보다
전체 상대·지연 강건성을 우선해 고속 아치를 채택한다.

## 기각한 후보

- **상대 공중 위상 동기화 수비:** 상대 y와 직전 y로 접촉 시점을 좁혔으나 선택
  자유도를 과소평가해 수비 위치가 무너졌다. 즉시 폐기했다.
- **느린 아치(`xMag=0`):** 강한 상대에 소폭 후퇴하고 기본 AI에 크게 회귀했다.
- **모든 공격을 아치로 변경:** 시도하지 않았다. 첫 서브 이후의 v7 공격은 이미
  검증됐고, 변경 범위를 한 번의 접촉으로 제한하는 것이 이번 개선의 안전장치다.

## 제출 판단

현재 물리와 실측 지연 1에서는 v9를 권장한다. v7의 강한 상대 성능을 보존하면서
구형 공격형 상대와 지연 변화에 더 강하다. 대회 당일 스킬로 서브 초기 상태나
스매시 물리가 바뀌면 `OPENING_SERVE=0`으로 v7 동작에 즉시 복귀할 수 있다.

## 아직 기각되지 않은 후속 제안

v5·v6 상대 서브 랠리 승률은 v7의 13.9%·14.2%에서 v9의 11.8%·12.9%로
소폭 낮아졌다. 따라서 다음 제안은 **아직 구현·측정하지 않았으며 기각되지 않았다.**

- `DEF_AIR=1`을 v7의 공중 낙하점 수정 이후 조건에서 다시 측정
- 첫 서브 옵션을 상대의 최속 요격과 반격까지 보는 2-ply로 채점
- 전역 `DEF_AIR`가 손해면 첫 서브 직후에만 공중 복귀를 허용

이 문서에서 기각한 "상대 공중 위상 동기화 수비"는 상대의 현재 y를 이용해
`planDefense`의 접촉점을 좁힌 별개의 실험이다. `DEF_AIR` 재측정이나 2-ply
서브 채점의 기각 근거가 아니다.
