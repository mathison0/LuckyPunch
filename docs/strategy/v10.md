# v10 — 2-ply 서브 채점 + 서브 직후 공중 복귀

> `src/code-here/LuckyPunch_v10.js` · v7 기반 · 현재 주력

## 한 줄 요약

첫 서브를 고를 때 직접 득점 가능성뿐 아니라 상대의 최속 요격·최선 반격까지
시뮬레이션하고, 실제 행동도 그 예측과 맞도록 공중에서 수비 위치로 즉시 복귀한다.
두 변경은 단독으로는 약하지만 결합하면 v5·v6 상대 서브 랠리를 약 14%에서
49~51%로 끌어올린다.

## 문제

v7은 v5·v6 상대 리시브 랠리의 89~90%를 이기지만 서브 랠리는 14%만 이겼다.
첫 스매시가 상대에게 어려운지만 평가하고, 상대가 요격해 되돌릴 반격과 내 후속
위치를 보지 않기 때문이다.

## 구현

`chooseHitServe()`는 첫 서브의 파워히트 6종을 각각 다음 순서로 평가한다.

1. 기존 `evaluateShot()`과 `scoreShot()`으로 1수 점수를 구한다.
2. 슛 궤적에서 상대가 점프해 닿을 수 있는 가장 이른 접촉을 찾는다.
3. 그 접촉에서 상대가 `chooseHit()`로 선택할 최선의 반격을 계산한다.
4. `planDefense()`가 정한 위치까지 내가 실제로 복귀할 수 있는 거리를 반영한다.
5. `1수 점수 + COUNTER_WEIGHT × (-상대 반격 점수)`가 가장 큰 서브를 고른다.

이 계산은 `rallyCrossings===0`인 진짜 첫 서브에만 실행한다. 나머지 랠리는 v7과
동일하다. `DEF_AIR_SERVE=1`도 내 서브 직후, 첫 반격이 오기 전까지만 켜진다.

## P1·P2·P3 독립 측정

lag1, 지터 `{0,8}`, 양 진영, 상대당 48세트. 표의 값은 `서브 랠리 / 세트`다.

| 실험 | v5 | v6 | 판정 |
|---|---:|---:|---|
| v7 기준 | 13.9% / 54.2% | 14.2% / 56.3% | 기준선 |
| P1 전역 `DEF_AIR=1` | 15.9% / 58.3% | 17.0% / 62.5% | 소폭 개선, 리시브 하락 |
| P2 2-ply 단독 | 12.5% / 62.5% | 12.2% / 60.4% | 서브 랠리 개선 없음 |
| P3 서브 복귀 단독 | 16.8% / 66.7% | 16.5% / 66.7% | 중간 개선 |
| **P2+P3, W=0.6** | **48.6% / 95.8%** | **46.6% / 95.8%** | 강한 시너지 |

P2 단독이 실패한 이유는 채점기가 복귀를 가정하지 않는데 실제 봇도 공을 쫓아가서,
반격 대비 위치가 바뀌지 않기 때문이다. P3와 결합하면 예측한 수비 위치와 실제
이동이 일치한다.

## 가중치 스윕

| `COUNTER_WEIGHT` | v5 서브 / 세트 | v6 서브 / 세트 |
|---:|---:|---:|
| 0.3 | 43.8% / 93.8% | 41.4% / 93.8% |
| 0.6 | 48.6% / 95.8% | 46.6% / 95.8% |
| **1.0** | **51.2% / 97.9%** | **49.2% / 95.8%** |

1.0이 강한 상대와 전체 풀 모두에서 가장 좋아 기본값으로 확정했다.

## 전체 풀

lag1, 지터 `{0,8}`, 양 진영, 상대당 48세트:

| 상대 | 전체 랠리 | 서브 랠리 | 리시브 랠리 | 세트 |
|---|---:|---:|---:|---:|
| v1 | 78.0% | 76.1% | 79.9% | 91.7% |
| v2 | 68.6% | 75.5% | 61.9% | 91.7% |
| v3 | 81.4% | 75.5% | 87.6% | 95.8% |
| v4 | 80.5% | 75.3% | 86.0% | 95.8% |
| v5 | 71.3% | 51.2% | 90.7% | 97.9% |
| v6 | 71.2% | 49.2% | 92.5% | 95.8% |
| v7 | 70.8% | 52.7% | 87.5% | 95.8% |
| v9 | 70.8% | 53.0% | 87.2% | 95.8% |

v1~v7 공통 풀 세트 평균은 v9의 79.8%에서 v10의 **94.9%**로 상승했다.
다만 약한 상대·지터 8·lag 1/2/3 벤치 종합은 v9 81.9%, v10 79.5%로 소폭
후퇴했다. 실측 lag1의 전체 프로토콜에서는 모든 상대에게 세트 91.7% 이상이므로,
강한 상대에 대한 큰 개선을 우선한다.

## 실행시간과 안전성

- v5 48세트 계측: `decide` 평균 0.511ms, 최대 4.268ms
- 목표 15ms와 hard timeout 360ms 안에 충분히 들어온다.
- 첫 서브가 아니면 2-ply 계산 비용은 0이다.
- `SERVE_2PLY=0`, `DEF_AIR_SERVE=0`으로 v7 동작에 복귀할 수 있다.

## 제출 판단

현재 물리와 실측 지연 1에서는 v10을 권장한다. v9의 첫 서브 고속 아치는 구형
상대에 강했지만 v5·v6 서브 랠리를 개선하지 못했다. v10은 약한 상대 세트 승률을
91.7% 이상 유지하면서 최신 계열 상대를 95.8~97.9%로 이긴다.
