# v11 — 서브 첫 접촉 공중 세팅

> `src/code-here/LuckyPunch_v11.js` · v10 기반 · 실측 lag1 공격형 변형

## 한 줄 요약

서브에서 점프는 유지하되 첫 접촉에 파워히트를 쓰지 않고 자기 코트에 한 번
띄운다. 즉시 반격당하는 3타 구조를 끊고 두 번째 접촉에서 공격한다. v10 직접
상대에는 강하지만 지연 2 이상에서 크게 약해져, 안정형 주력은 v10으로 유지한다.

## 검증한 두 제안

### 1. 점프하지 않고 지상에서 받기 — 기각

서브 공 바로 아래로 이동해 `vx≈0`인 몸통 리턴을 만들고, 지상 상태를 유지한 채
두 번째 접촉을 준비했다. v5·v6 서브 랠리는 약 63%까지 올랐지만 상대에게 긴
재배치 시간을 주어 약한 공격형 상대에게 크게 무너졌다.

| 상대 | 지상 세팅 세트 승률 |
|---|---:|
| v1 | 100.0% |
| v2 | **33.3%** |
| v3 | **68.8%** |
| v4 | **58.3%** |
| v5 | 91.7% |
| v6 | 95.8% |

과거 v8 다단 운반과 같은 문제가 다시 나타났다. 지상에 남는 이익보다 상대가
두 번째 공격을 완전히 준비할 시간이 더 컸다.

### 2. 점프하되 바로 넘기지 않기 — 채택

v10의 점프 타이밍은 그대로 쓰고, 첫 접촉 순간 `hit=0`으로 몸통 리턴을 만든다.
첫 공은 자기 코트에 뜨고 두 번째 접촉부터 기존 v10 공격으로 복귀한다.

```js
if (AIR_SERVE_SET === 1 && openingServe) {
  return { x: xToBall, y: 0, hit: 0 };
}
```

46-2로 이겼다. 지터 포함 프로토콜의 75%보다 낙관적인 값이므로 공식 비교에는
위 표의 75%를 사용한다.

## 지연 강건성

약한 상대 AI·v1·v2·v3, 지터 8, lag 1/2/3 종합:

| | 종합 승률 | 득실 |
|---|---:|---:|
| v10 | **79.5%** | 2678-1618 |
| v11 | **59.0%** | 2380-2071 |

lag1 평균은 v10 87.5%, v11 86.5%로 비슷하다. 그러나 lag2에서 두 번째 접촉
타이밍이 어긋나 AI 8%, v2 13%까지 떨어진다. 대회 환경의 반영 지연이 실측값
1임을 확신할 때만 쓸 수 있다.

## 실행시간과 판단

- `decide` 평균 약 0.3~0.5ms
- 보통 최대 7.6ms 이하, 전체 측정 중 단일 최대 40.4ms
- 예외 0회, hard timeout 360ms 이내

**안정형 제출 권장은 v10을 유지한다.** v11은 lag1이 확실하고 v10 계열 상대를
강하게 의식할 때 선택할 공격형 변형이다. `AIR_SERVE_SET=0`이면 v10 동작으로,
`GROUND_SERVE_SET=1`이면 기각된 지상 세팅 실험으로 전환된다.
